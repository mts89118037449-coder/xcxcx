# Flappy Bird для Telegram 🐤

Игра Flappy Bird в виде Telegram Mini App плюс бот с таблицей рекордов и покупками за Telegram Stars.

```
flappy-telegram/
├── webapp/index.html   — сама игра (один файл, canvas, без зависимостей)
└── bot/bot.js          — бот + HTTP-сервер (игра и API), Node.js 18+, без npm-зависимостей
```

## Возможности

- Пиксельная птичка как в оригинале, с анимацией крыльев.
- Медали за 5 / 10 / 20 / 40 очков, рекорд сохраняется автоматически (CloudStorage + бот).
- **Скины:**
  - Классика — сразу.
  - Красная — рекорд 5, Синяя — 10, Зомби — 25, Фламинго — 50.
  - За Stars: Золотая — 25 ⭐, Ниндзя — 50 ⭐, Алмазная — 100 ⭐.
- **«Продолжить» за Stars.** Разбился — можно продолжить с тем же счётом.
  Внутри одной попытки каждое следующее продолжение дороже:
  1 → 3 → 7 → 15 → 30 → 60 → 120 → 250 → 500 → 1000 → 2500 → 5000 → 10000 ⭐.
  «Заново» сбрасывает цену.
- Бот: `/start`, `/play`, `/top` (топ‑10), `/me`, `/paysupport`, кнопка «Играть» в меню чата.

Цены задаются в двух местах (должны совпадать): `CONTINUE_PRICES` и `SKINS` в
`webapp/index.html`, `CONTINUE_PRICES` и `SKIN_PRICES` в `bot/bot.js`. Сумму списывает
сервер — он сам считает, какое по счёту продолжение покупается, и отклоняет устаревшие счета.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и получите токен.
   Для Stars ничего подключать не нужно.
2. Запустите бота — он же раздаёт игру и API на `PORT` (по умолчанию 8080):

   ```bash
   cd flappy-telegram/bot
   BOT_TOKEN=123456:ABC... WEBAPP_URL=https://ваш-адрес/ npm start
   ```

3. Сделайте порт доступным по HTTPS (например, `ngrok http 8080`) и укажите этот адрес в `WEBAPP_URL`.
   Если игру хостите отдельно (GitHub Pages и т.п.), укажите адрес бота параметром:
   `WEBAPP_URL=https://игра/?api=https://адрес-бота`.
4. Откройте бота в Telegram → `/start` → «🐤 Играть».

Данные игроков (рекорды, купленные скины) хранятся в `bot/scores.json`.

## Локальная проверка игры

```bash
cd flappy-telegram/webapp && python3 -m http.server 8080
```

Откройте http://localhost:8080. Вне Telegram игра работает в демо-режиме: покупки проходят без оплаты.
