# Flappy Bird для Telegram 🐤

Игра Flappy Bird в виде Telegram Mini App плюс бот с таблицей рекордов.

```
flappy-telegram/
├── webapp/index.html   — сама игра (один файл, canvas, без зависимостей)
└── bot/bot.js          — бот на Node.js 18+ (без npm-зависимостей)
```

## Возможности

- Классический геймплей: тап по экрану (или пробел) — птица подпрыгивает, пролетай между трубами.
- Медали за 5 / 10 / 20 / 40 очков, личный рекорд хранится в Telegram CloudStorage.
- Вибрация (HapticFeedback) при взмахе, наборе очка и столкновении.
- После проигрыша появляется кнопка «Отправить результат» — очки уходят боту.
- Бот: `/start`, `/play`, `/top` (топ‑10), `/me` (мой рекорд), кнопка «Играть» в меню чата.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и получите токен.
2. Разместите `webapp/index.html` на любом HTTPS-хостинге (GitHub Pages, Netlify, Vercel…)
   **или** дайте боту раздавать его самому через `PORT` и пробросьте HTTPS, например:
   `ngrok http 8080`.
3. Запустите бота:

   ```bash
   cd flappy-telegram/bot
   BOT_TOKEN=123456:ABC... WEBAPP_URL=https://ваш-адрес/ PORT=8080 npm start
   ```

   `PORT` можно не указывать, если игра лежит на внешнем хостинге.
4. Откройте бота в Telegram, нажмите `/start` → «🐤 Играть».

Рекорды сохраняются в `bot/scores.json`.

> Отправка результата (`Telegram.WebApp.sendData`) работает, когда игра открыта
> кнопкой «🐤 Играть» на клавиатуре бота. Из кнопки меню играть тоже можно,
> но рекорд тогда сохраняется только в CloudStorage игрока.

## Локальная проверка игры

```bash
cd flappy-telegram/webapp && python3 -m http.server 8080
```

и откройте http://localhost:8080 в браузере.
