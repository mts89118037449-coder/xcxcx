# Универсальный загрузчик для Android

Делитесь ссылкой из любого приложения → **Termux** → файл появляется в «Загрузки/Загрузчик».

Поддерживается: YouTube, YouTube Music, TikTok, X/Twitter, Instagram, VK, Одноклассники,
Rutube, Reddit, Pinterest, SoundCloud, Twitch-клипы, Spotify (треки) и ещё около 1800 сайтов
(всё, что умеют [yt-dlp](https://github.com/yt-dlp/yt-dlp) и [gallery-dl](https://github.com/mikf/gallery-dl)).

## Установка (один раз, ~5 минут)

1. Установите **Termux** с F-Droid: https://f-droid.org/packages/com.termux/
   (версия в Google Play устарела и не работает).
2. По желанию поставьте **Termux:API** оттуда же: https://f-droid.org/packages/com.termux.api/.
   Тогда появятся уведомления «Скачано» и файлы будут сразу видны в галерее.
3. Скачайте на телефон файл [`install.sh`](install.sh): на GitHub откройте файл и нажмите «Download raw file».
   Он попадёт в папку «Загрузки».
4. Откройте Termux и выполните по очереди:
   ```bash
   termux-setup-storage
   bash ~/storage/downloads/install.sh
   ```
   На первой команде разрешите доступ к файлам.

> Если сделать репозиторий публичным, шаги 3–4 сводятся к одной команде:
> `curl -sL https://raw.githubusercontent.com/mts89118037449-coder/xcxcx/main/android-downloader/install.sh | bash`

## Как пользоваться

- В YouTube, TikTok, Instagram, Spotify и других приложениях нажмите **Поделиться → Termux**.
- Откроется окно с выбором:
  `1` видео в лучшем качестве, `2` видео до 720p, `3` только звук MP3.
  Если ничего не нажать, через 8 секунд выберется вариант по умолчанию:
  для музыкальных сайтов MP3, для остальных видео.
- Готовый файл лежит в **Загрузки/Загрузчик**.
- Вручную тоже можно: `dl https://...`

Ссылку можно отправлять вместе с текстом («Смотри! https://vm.tiktok.com/…»), загрузчик сам её найдёт.
Посты без видео (фото, карусели) скачиваются как картинки.

## Spotify

Spotify отдаёт музыку только в зашифрованном виде, поэтому загрузчик берёт со страницы
название и исполнителя трека и скачивает этот же трек в MP3 с YouTube.
Работает для ссылок на **отдельные треки**. Плейлисты и альбомы не поддерживаются.

## Если пишет «нужен вход» (Instagram, приватные видео, иногда YouTube)

Нужен файл cookies от вашего аккаунта:
1. Поставьте браузер с расширениями (Kiwi Browser или Firefox) и расширение «Get cookies.txt LOCALLY».
2. Войдите на нужный сайт, экспортируйте cookies в файл `cookies.txt` (он попадёт в «Загрузки»).
3. В Termux: `cp ~/storage/downloads/cookies.txt ~/`

Загрузчик сам начнёт использовать этот файл. **Никому не передавайте `cookies.txt`**: это доступ к вашему аккаунту.

## Обновления

Раз в неделю загрузчик сам обновляет yt-dlp и gallery-dl, потому что сайты часто меняются.
Если что-то перестало качаться, обновите вручную: `pip install -U yt-dlp gallery-dl`.

## Важно

Скачивайте только то, что можно сохранять для личного использования: свои видео,
свободно распространяемый контент и то, на что у вас есть права.
