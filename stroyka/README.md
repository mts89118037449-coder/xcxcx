# Стройка 3D — визуализация хода строительства

3D-модель корпусов МКД. Структура берётся из таблиц: каждый лист «Секция …» в «Выполнении» — отдельный корпус, этажность — по столбцу «Этаж» (сейчас секции 4 и 5, 16 этажей + подвал + кровля). Добавили лист «Секция 6» — в 3D появится третий корпус. Каждый этаж заполняется зелёным, как прогресс-бар: доля длины фасада равна проценту выполнения. Данные берутся из Google-таблицы «Glorax_Учёт» и записываются обратно.

## Что умеет

- **3D-сцена** (three.js 0.170): вращение, масштаб, наведение показывает процент этажа, клик открывает этаж для редактирования. Красная метка на торце означает открытые поручения по этажу (лист «Замечания АСГ»).
- **Переключатель работ**: все работы (среднее) / наружные стены / перегородки.
- **Режимы «Прогресс / Проект»**: в «Прогрессе» готовая часть этажа показана зелёным фасадом, а остальное — каркасом (плиты, колонны). «Проект» показывает здания целиком, как на проектных рендерах: светлый фасад с вертикальными пилонами, медный верх, остеклённый первый этаж. Вокруг — парк с прудом, дорога и парковка.
- **Сводка**: процент по секциям и видам работ, 2D-фасад по этажам, открытые поручения (у каждого — ссылка на этаж).
- **Этаж**: нажмите этаж в 3D или на фасаде — откроются категории со сводкой: Работы, Замечания, Документы (ИС/АОСР), Материал на этаж, Люди и бригады, Статус этажа. Нажатие разворачивает категорию; красный маркер на модели открывает этаж сразу на «Замечаниях». На телефоне этаж выезжает снизу шторкой (смахните вниз или ✕, чтобы закрыть); колонки ИС/АОСР/замечаний находятся по шапке листа «Таблица», поэтому новые секции подхватываются сами.
- **Этаж**: ползунки процентов по каждому виду работ, статусы ИС и АОСР и замечания из листа «Таблица».
- **Календарь**: на каждый день — сколько людей вышло (по секциям) и какой материал приехал. Есть добавление и удаление записей, итоги материала за месяц, сроки поручений.

- **Учёт** — 4 раздела:
  - *Расходы* (лист «Счета»): итоги, разбивка по категориям, график по месяцам, крупнейшие получатели, поиск и фильтр. Новый расход можно добавить, и он запишется строкой в «Счета».
  - *Авансы* (лист «Для РП»): авансы за номинированный материал по статусам, поставщикам и месяцам.
  - *Поставки*: материал из журнала и из листа «Номинированные материалы» с итогами по позициям.
  - *Поступления* (лист «Оплаты Глоракс»): поступления и баланс против расходов.
- **Календарь** показывает не только людей и поставки, но и расходы по дням.
- **3D-тур** (кнопка «▶ 3D-тур»): при прокрутке камера облетает дома, этажи строятся снизу вверх до текущего процента, а на карточках выводятся цифры по секциям, материалу и деньгам.
- **Мобильный вид**: 3D закреплено сверху, вкладки в нижней панели, при прокрутке страницы модель поворачивается, кнопка ⤢ разворачивает 3D.

## Свой сервер и бэкапы

Приложение можно держать на своём сервере, независимо от Google и CDN. Бэкапы делаются автоматически, есть «Скачать копию» и «Восстановить» в приложении и офлайн-режим на телефоне. Установка на VPS одной командой (`deploy/install.sh`) и все команды — в [DEPLOY.md](DEPLOY.md).

## Запуск

Сборка не нужна, это статические файлы:

```sh
cd stroyka
node server/server.js        # затем откройте http://localhost:8080 — данные хранятся в stroyka/data/
```

Можно выложить на любой статический хостинг (GitHub Pages, Netlify и т. п.).

## Подключение к Google-таблице (чтение и запись)

1. В таблице откройте **Расширения → Apps Script** и вставьте `apps-script/Code.gs`.
2. Выполните функцию `setup`. Она создаст два листа:
   - **«Прогресс»**: Секция | Этаж | Вид работ | Процент | Обновлено. Лист создаётся пустым — проценты считаются по «Выполнению», здесь только ручные значения.
   - **«Журнал»**: Дата | Секция | Тип (Люди/Материал) | Наименование | Количество | Ед. | Примечание | ID.
   Финансовые листы («Счета», «Для РП», «Оплаты Глоракс», «Номинированные материалы») скрипт только читает. Единственная запись туда — новая строка в «Счета» по кнопке «+ Добавить расход»; в примечании она помечается «[из приложения]».
3. (Необязательно) В свойствах скрипта задайте `TOKEN` — пароль для записи.
4. **Развертывание → Веб-приложение**: «Запуск от имени: я», «Доступ: все». Скопируйте URL `…/exec`.
5. В приложении нажмите **«Таблица…»** и вставьте URL (и токен). Ещё можно открыть приложение со ссылкой `?api=URL&token=…`.

### Синхронизация в обе стороны

- **Приложение → таблица, сразу.** Каждая правка (процент этажа, люди, поставка, расход, их исправление и удаление) применяется на экране и тут же отправляется в таблицу. Статус вверху: «Сохранение…» → «✓ Записано в таблицу».
- **Нет связи на объекте** — правка не теряется. Она ждёт в очереди на устройстве (статус «Нет связи · в очереди N») и уходит сама, когда связь появится.
- **Таблица → приложение, за ~10 секунд.** `setup` ставит триггеры «при изменении», которые отмечают любую правку в таблице. Приложение проверяет отметку каждые 10 секунд, а также при возврате на вкладку, и подтягивает свежие данные. Пока вы заполняете форму, экран не перерисовывается — данные применятся, когда закончите ввод.
- **«Счета»:** строки, внесённые в таблице вручную, можно исправить из приложения, а удалить — только в таблице. Перед записью сервер сверяет сумму: если строку успели изменить в таблице, перезаписи не будет, и приложение об этом скажет. Расходы, добавленные из приложения, помечаются в примечании `[app:…]`, их можно и исправлять, и удалять.
- Строки, добавленные в «Журнал» вручную, получают ID автоматически.

Пока таблица не подключена, приложение показывает её снимок на 04.11.2026, а правки сохраняются только на этом устройстве. После подключения вставьте URL в `js/config.js` (`API_URL`) — тогда приложение у всех сразу будет открываться онлайн.

## Файлы

- `index.html`, `css/style.css` — интерфейс
- `js/scene.js` — 3D-сцена
- `js/data.js` — модель данных и синхронизация
- `js/main.js` — вкладки, календарь, формы
- `js/config.js` — URL Apps Script по умолчанию
- `js/seed.js`, `js/seed-fin.js` — снимок таблицы на 04.11.2026 (пока нет онлайн-подключения)
- `apps-script/Code.gs` — API на стороне таблицы
- `server/server.js` — свой сервер: приложение, API, бэкапы, копия Google-таблицы
- `sw.js` — офлайн-режим
- `vendor/three/` — three.js 0.170 (MIT), чтобы не зависеть от CDN
- `Dockerfile`, `docker-compose.yml`, `deploy/` — развёртывание
