Подключение к Google Таблице

Чтобы приложение читало и записывало данные в таблицу «Glorax_Учёт», в ней нужно один раз установить скрипт из stroyka/apps-script/Code.gs. Без подключения работает демо-режим: данные снимка таблицы, правки хранятся только в этом браузере.

  1. Таблица → Расширения → Apps Script, вставьте код из Code.gs, сохраните.
  2. Запустите функцию setup (создаст листы «Прогресс» и «Журнал»).
  3. Начать развертывание → Веб-приложение: «Запуск от имени: я», «Доступ: все». Скопируйте URL.
  4. Вставьте URL ниже. Если в свойствах скрипта задан TOKEN — укажите его.
