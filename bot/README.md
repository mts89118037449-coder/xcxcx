# «КП за минуту» — Telegram-бот, который зарабатывает сам

**Что это:** бот в Telegram, который за 1 минуту делает продающее коммерческое
предложение (готовый файл Word) под конкретного клиента. Пользователь отвечает
на 5 вопросов, бот пишет текст через Gemini и присылает оформленный `.docx`.

**Почему это может быть пассивным доходом:**

| Что происходит | Кто это делает |
|---|---|
| Привлечение пользователей | реферальная программа: друг купил, пригласившему 2 КП бесплатно |
| Продажа | бот: первое КП бесплатно, дальше предлагает пакеты |
| Приём оплаты | Telegram Stars: не нужны эквайринг, ИП/ООО и касса на старте |
| Выполнение заказа | бот + Gemini, 15–30 секунд |
| Отчётность | бот присылает вам «💰 +300 ⭐» на каждую покупку, `/stats` показывает сводку |

От вас нужно только запустить бота один раз и периодически выводить Stars.

## Цены (меняются в `bot/index.ts`, массив `PACKAGES`)

| Пакет | Цена |
|---|---|
| 1 КП | 75 ⭐ |
| 5 КП | 300 ⭐ |
| 20 КП | 900 ⭐ |

Себестоимость одной генерации на Gemini Flash — доли рубля, почти всё остаётся вам.

## Запуск за 10 минут

1. **Создайте бота:** напишите [@BotFather](https://t.me/BotFather), отправьте `/newbot` и получите токен.
2. **Получите ключ Gemini:** https://aistudio.google.com/apikey (у вас он уже есть для AI Studio).
3. **Узнайте свой Telegram id:** напишите [@userinfobot](https://t.me/userinfobot).
4. Создайте файл `.env` в корне проекта по образцу [`bot/.env.example`](.env.example).
5. Запустите:
   ```bash
   npm install
   npm run bot
   ```

Чтобы бот работал круглосуточно, нужен сервер: подойдёт любой VPS от 200–300 ₽/мес
(Timeweb, Selectel, Aeza и т.п.). На сервере:
```bash
npm install -g pm2
pm2 start "npm run bot" --name kp-bot
pm2 save && pm2 startup
```

## Команды

Для всех: `/new`, `/buy`, `/balance`, `/invite`, `/paysupport` (обязательна по правилам Telegram для оплаты в Stars).

Только для администратора (`ADMIN_ID`):
- `/stats`: пользователи, созданные КП, покупки, заработанные звёзды;
- `/reply <id> <текст>`: ответить пользователю на обращение в поддержку;
- `/refund <id> <charge_id>`: вернуть платёж (charge_id хранится в `bot/data/db.json`).

## Как вывести деньги

Накопленные Stars выводятся через [Fragment](https://fragment.com) в TON
(в @BotFather: бот → Balance). Дальше TON можно продать за рубли на бирже или в P2P.
Вывод доступен после холда (сейчас около 21 дня с момента оплаты).

## Честно о рисках

- Никакой продукт не гарантирует доход. Первые недели уйдут на то, чтобы получить
  первых пользователей. Потом бот работает сам.
- Gemini может ошибиться. В промпте запрещено выдумывать цифры, но клиент
  должен проверить КП перед отправкой.
- Данные хранятся в `bot/data/db.json`. Делайте резервную копию этого файла.
