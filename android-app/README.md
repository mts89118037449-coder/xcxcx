# SoundAura 6.3 — музыка без цензуры для Android

Слушать, скачивать и делиться музыкой и видео. Без рекламы.

## Что нового в 9.34

Перепроверка без телефона (с сервера и по коду):
- **SoundCloud через телефон проверен на 12 песнях из журналов:** звук есть у 11 (AAC 160 кбит/с, поток без шифрования, кусочки скачиваются), в том числе у «Кальций» и «с кем бы я ни уснул», которые раньше «не находились»; поиск со звуком — 2–3,5 с (первый раз ~6,7 с). Не отдаётся только «наше последнее лето — падаю вниз».
- **Сравнение названий проверено на 19 случаях из журналов** (транслит, чужие песни с тем же названием, live/sped up/remix): ошибок 0.
- **Окно источников ищет сразу, в своём потоке.** Раньше оно могло стоять в очереди за фоновыми опросами (те ждут до 3 минут, пока вы что-то включаете) и за запуском yt-dlp.
- **«Аура дня»: из прошлых подборок — правда не больше четверти.** Подборка по тегам свободно брала песни из прошлых наборов (в журнале было 13 из 40); теперь — только если нового не хватает. Если закрыть окно во время сборки, музыка всё равно включится.
- **«Медиатека на телефоне»** больше не пишет «не нашлось» про песни, найденные на SoundCloud: они играют из сети (поток по кусочкам на телефон не кладётся) и считаются отдельно.

## Что нового в 9.33

- **SoundCloud — без yt-dlp.** Звук SoundCloud теперь берёт сам телефон (NewPipe, без Python), одновременно с yt-dlp — кто первым. Раньше единственным путём был yt-dlp: то файл входов портился, то под нагрузкой он не отвечал, то писал «No suitable extractor». Проверено с сервера на ваших треках: AAC 160 кбит/с за 1,3–5 с, в том числе на треке, где yt-dlp на телефоне отказывал; платные (DRM) отказывают сразу, а не висят. Движок yt-dlp для SoundCloud больше не ждём при запуске.

## Что нового в 9.32

По журналу 17.11 (зависания до 7 с, SoundCloud и YouTube через yt-dlp «не ответила за 8 с» почти везде):
- **Телефон больше не душит фоновая загрузка.** «Медиатека на телефоне» и сохранение прослушанной песни запускали на каждую песню отдельный процесс Python (yt-dlp) — по два одновременно; процессор был занят, поиск и интерфейс стояли. Теперь песня качается обычной загрузкой по уже найденной ссылке, кусками по 1 МБ, по одной и с низким приоритетом; поток по кусочкам (HLS) в фоне не качается.
- **Плавнее переход в плеер.** Дым рисовал десятки слоёв больше экрана на каждый кадр — отсюда «зависания 2,5–7 с» при открытии плеера. Клубов вдвое меньше, они не больше экрана, тень — только у облаков от нот.
- **Главный экран не стоит 2–2,7 с:** любимые исполнители больше не пересчитываются по всей медиатеке при каждом показе.
- **Запуск:** фоновые задачи старта (движок yt-dlp, текстура дыма, теги, Telegram, журнал) идут с низким приоритетом — окно получает процессор первым (журнал: 6,7 с на создании главного окна).

## Что нового в 9.31

- **«Аура дня»: каждое нажатие — новая сборка**, даже через секунду; прошлая подборка играет, пока собирается новая. Песни прошлых подборок, которые вы уже прослушали или пропустили, в новую не попадают; те, до которых не дошли, могут появиться снова.
- **Заставка — сразу и коротко:** дым с первого кадра (текстура готовится при запуске приложения, дым не «разгоняется» с нуля), текст — просто «Собираю твою ауру…». Нажатие по заставке прячет её, сборка продолжается.
- **Сборка быстрее:** радио любимых исполнителей прогреваются при запуске и запоминаются на 30 минут, четыре радио берутся одновременно.

## Что нового в 9.30

- **Заставка сборки «Ауры дня».** Если набор ещё не готов, вместо строки снизу — экран с клубящимся дымом в цветах ауры, крупно «Аура дня» и по шагам, что происходит: какие исполнители сегодня в основе, сколько песен нашлось в их радио, какие ваши теги используются для нового, сколько песен смешано и сколько из них новых, какая включается первой. Уходит плавно, когда включается песня.

## Что нового в 9.29

- **«Аура дня» — новый набор при каждом нажатии.** Каждый раз берутся другие любимые исполнители (четверо из двенадцати самых любимых) и другая часть новых песен по тегам; песни двух прошлых наборов избегаются — повторов не больше четверти. Следующий набор готовится заранее, пока играет текущий, поэтому нажатие по-прежнему играет сразу.

## Что нового в 9.28

- **Быстрее запуск и интерфейс.** В приложение встроен профиль запуска: Android заранее компилирует код приложения (и библиотек плеера и интерфейса) в машинный, а не разбирает его на лету при каждом холодном старте — это работает и для APK не из магазина. Профиль применяется в фоне после установки, полный эффект — со второго-третьего запуска.
- **Запуск разгружен.** Из главного потока убрано всё, что не нужно в первую секунду: запуск Telegram (нативная библиотека), ярлыки, теги, проверка новинок и проверка файлов кэша на диске.

## Что нового в 9.27

- **Теги у каждой песни.** Жанр (по альбому в Deezer), язык, приметы в названии (slowed, speed up, phonk, jumpstyle, remix, акустика, live…), «без цензуры», а у дослушанных — темп (медленная / средний темп / быстрая) и «басовая», измеренные в самом звуке. Жанры любимых песен подтягиваются фоном, понемногу и не мешая музыке. Ваши главные теги видны на карточке «Аура дня».
- **Новые песни по вкусу.** Раз в день приложение берёт исполнителей, похожих на любимых (по Deezer: для playingtheangel это Три дня дождя, найтивыход, ЛСП, pyrokinesis…), и чарт вашего жанра, отбрасывает то, что уже есть или что вы пропускали, и ранжирует по совпадению тегов.
- **«Аура дня» — одна на весь день и сразу.** Раньше она собиралась заново при каждом нажатии (несколько секунд и каждый раз другая). Теперь собирается заранее при запуске, хранится до конца дня, первые песни готовятся заранее; каждая третья песня — новая по вашим тегам.
- **Ускорение — по фактам.** В журнал пишется время запуска и каждое «ЗАВИСАНИЕ ИНТЕРФЕЙСА» дольше 0,4 с с местом в коде — по ним дальше чиню конкретные тормоза.

## Что нового в 9.26

- **Бас — ярче и чётче.** Удар баса теперь даёт короткий отчётливый толчок: свечение у обложки вспыхивает сильнее и раздувается шире, весь дым на миг толкается наружу и светлеет, облака от баса ярче остальных. Вспышка набирается за ~35 мс и спадает за ~150 мс — чётко, но без дёрганья.

## Что нового в 9.25

- **Дым без рывков.** Облако короткой ноты раньше мгновенно «перескакивало» к концу жизни, лишние облака исчезали разом, а на ударах дым ускорялся скачком, и после паузы ноты выпускались пачкой. Теперь всё плавно: короткие и лишние облака тают за 0,7 с, скорость течения и вспышка меняются мягко, после паузы старые ноты пропускаются.

## Что нового в 9.24

- **Дым снова дым.** Вместо гладких кругов с контуром — рваные клубы с завихрениями (текстура дыма, в цвет края обложки), медленно закручиваются на лету. Слои отделяются плотностью и лёгкой тенью под новым клубом, а не обводкой; белой каши нет — клубы не складывают яркость. Короткая нота — её облако быстро тает, протяжная — живёт дольше; новые ложатся сверху.

## Что нового в 9.23

- **Дым слоями, без белой каши.** Облака больше не складывают яркость (из-за этого всё сливалось в белое пятно), а ложатся друг на друга слоями: у каждого мягкое полупрозрачное тело, светлый ободок и тонкий тёмный контур, под ним — тень. Новые облака видны поверх старых, цвета обложки не выгорают.

## Что нового в 9.22

- **Фон больше не забивает поиск.** Журнал 17.11: пока «Медиатека на телефоне» качала любимые песни, а соседние песни готовились заранее, yt-dlp был перегружен («площадка не ответила за 8 с» почти у всех), и нажатая песня и окно источников ничего не получали. Теперь вся фоновая работа замолкает, пока вы что-то включаете или открываете источники, и ещё 20 секунд после.
- **Зависшая ссылка больше не съедает весь поиск.** YouTube Music находил песню («✓»), но ссылка на звук не приходила, и поиск через 25 с сдавался без объяснения. Теперь ссылка ждётся не дольше 15 с, а в журнале пишется «ссылка на звук не пришла за 15 с».
- SoundCloud теперь отвечает по-настоящему (ошибка файла входов ушла): часть треков у него платная (DRM) — такие пропускаются.

## Что нового в 9.21

- **Дым — клубами, а не струйками.** Приложение слышит три полосы звука: бас, середину (голос, гитары, клавиши) и верх (тарелки, хэты). Каждая нота выпускает из обложки широкое облако веером: от баса — самые большие и медленные, от середины — средние, от верха — поменьше и быстрее. Чем больше частот звучит разом, тем облака шире, гуще и их больше — они накладываются друг на друга. Фоновый дым тоже становится крупнее и плотнее, когда музыка «полная».

## Что нового в 9.20

- **Окно источников — главный приоритет.** Раньше оно подхватывало уже идущий фоновый опрос площадок: тот шёл в последнюю очередь и пропускал YouTube после сбоев. Теперь, когда вы открываете окно, площадки опрашиваются заново, сразу и вне очереди; готовый непустой список показывается мгновенно.
- **«Отправить журнал» — новые записи сверху.** Журнал вставляют в чат текстом, и конец обрезается — так пропал весь запуск 9.19, а виден был только 9.17.

## Что нового в 9.19

- **SoundCloud, Rutube и Яндекс снова отдают звук.** Причина всех «Сайт требует вход» — испорченный файл входов (cookies.txt): yt-dlp после каждого запроса перезаписывает его, и если приложение закрывалось в этот момент (или два запроса писали одновременно), файл оставался пустым — и каждый следующий запрос через yt-dlp падал. Теперь каждый запрос работает со своей копией, общий файл никто не перезаписывает, а испорченный чинится при запуске (в журнале — строка «КУКИ: …»). Проверено на сервере: с пустым файлом прежняя версия падала с той же ошибкой, что на телефоне, новая играет.

## Что нового в 9.18

- **Нажатую песню ищем везде.** После пары сбоев сети YouTube и YouTube Music на несколько минут «выключались» — и для нажатой песни тоже: «Три дня дождя — Кальций» из-за этого «не нашлась» и пропустилась. Теперь пропуск действует только на подготовку в фоне.
- **Окно источников пишет в журнал** строку «ИСТОЧНИКИ «песня»: найдено N» и ответ каждой площадки — раньше оно искало молча.
- **Исходная ошибка площадки** теперь прямо в строке «не играет», в угловых скобках ‹yt-dlp …›: строки «ОШИБКА yt-dlp» в журнал почему-то не попадали.
- «Медиатека на телефоне» не ищет мусор от переноса (где название совпадает с исполнителем, например «Поиск в плейлисте — Поиск в плейлисте»).

## Что нового в 9.17

- **Журнал без мусора.** При каждом запуске приложения прошлые запуски, где всё работало, из журнала убираются. Остаются только запуски со сбоями — ошибка, песня не нашлась или не пошла, пауза не по кнопке и не от наушников, старт дольше 5 с (не больше пяти последних). Каждый запуск в журнале начинается строкой «=== ЗАПУСК SoundAura … ===».

## Что нового в 9.16

- **Нажатая песня — первой.** Соседние песни очереди начинают готовиться только когда нажатая зазвучала (или через 8 с). Журнал 17.11: «КТО УБИЛ МАРКА?» ждала 12,7 с, пока рядом искались две следующие и отнимали сеть.
- **Исходная ошибка любой площадки — в журнале** (строка «ОШИБКА yt-dlp …»). В 9.14 она писалась только с одного пути, и для SoundCloud так и не появилась. У YouTube Music теперь тоже видна причина «не играет».

## Что нового в 9.15

- **Окно «Откуда играть» больше не пишет «нигде не нашлась» для песни, которая есть.** Источники начинают собираться в фоне через секунду после старта песни; если сама песня в это время ещё искалась, фоновый опрос уступал ей сеть и заканчивался пустым — и этот пустой список держался полчаса. Теперь пустой список не запоминается, окно опрашивает площадки заново, а внизу есть «Искать ещё раз».
- **Нижнее меню на всех экранах.** В подборке, у исполнителя, в эквалайзере, переносе и Telegram внизу то же меню вкладок, над ним — полоска «сейчас играет». Нажатие на вкладку возвращает на главный экран в неё.
- **Карточка исполнителя:** из ваших песен показываются первые пять и «Показать все» — до «Популярного» и альбомов больше не надо листать.

## Что нового в 9.14

- **Названия латиницей.** YouTube Music иногда отдаёт русские песни транслитом («Meteoritnyj dozhd», «Avtopley» у ЛСП) — раньше они отсеивались как «другое название», теперь совпадают с «Метеоритный дождь», «Автоплей».
- **Исходная ошибка в журнале.** SoundCloud на телефоне на все песни отвечает «требует вход», а с сервера тот же поиск играет без входа. Теперь в журнал пишется исходный текст ошибки yt-dlp и его версия (в шапке) — по ним будет видно, что на самом деле отвечает сайт.
- **VPN, запрещающий обход.** Если VPN не пускает приложение мимо себя (ошибка EPERM в журнале), запасной путь «YouTube напрямую» больше не пробуется.

## Что нового в 9.13

- **Исполнитель кириллицей и латиницей — одно и то же.** «Skriptonit» и «Скриптонит», «Oxxxymiron» и «Оксимирон», «pyrokinesis» и «Пирокинезис» больше не отсеиваются как «другой исполнитель» (так YouTube Music не давал «Скриптонит — Baby mama»).
- **Журнал короче.** Когда Zaycev или другая площадка не нашла ничего похожего, вместо списка чужих песен пишется «ничего похожего» — журнал помещается в сообщение целиком.

## Что нового в 9.12

- **Дым и диск попадают в ритм.** Время удара теперь берётся по часам самого звука: удары ищутся в том, что проигрыватель отдаёт на выход, с меткой времени записи, и сравниваются с тем, что звучит прямо сейчас — с учётом задержки динамика или Bluetooth, которую меряет сам проигрыватель. Раньше задержка угадывалась, и вспышки расходились со звуком.
- **Музыка не кончается.** Когда очередь подходит к концу, дальше идёт похожая музыка. Раньше продолжение искалось только от последней песни — её исполнителя нет в каталоге или сеть моргнула, и всё останавливалось. Теперь пробуются и другие песни очереди, и любимые, в крайнем случае — популярное; нет сети — повтор через 15 секунд. В журнале — строки «РАДИО».

## Что нового в 9.11

- **Диск переворачивается.** Нажатие на диск в плеере («Кольцо») переворачивает его; с обратной стороны — компакт-диск на свету: серебро, два радужных веера отражения, тонкие дорожки. Пока музыка играет, блик ходит по кругу и вспыхивает на ударах. Ещё одно нажатие — обратно к обложке.

## Что нового в 9.10

- **Ритм дыма больше не срывается.** Звук подаётся в проигрыватель рывками, а удары привязывались ко времени обработки — удары одного рывка слипались или пропадали. Теперь время удара считается по самому звуку с учётом того, сколько его лежит в буфере; для Bluetooth-наушников добавлена поправка на их задержку. После перемотки и смены песни старые удары сбрасываются.

## Что нового в 9.9

- **Дым ярче и струится от битов.** На каждый удар из обложки вырываются струи дыма, а всё облако рывком расходится наружу; между ударами оно еле плывёт. Клубов больше, они плотнее и при наложении складываются в свет.

## Что нового в 9.8

- **Песня без картинки.** Обложка теперь берётся у записи с площадки, откуда песня играет, а если и там нет — ищется в каталоге и появляется сама. Пока картинки нет: на диске значок ноты, фон, дым и бегунок спокойные серебристые, а не яркие цвета приложения.

## Что нового в 9.7

- **Бегунок плеера — цвета основного акцента обложки** (и кольцо, и волна). У серой или чёрно-белой обложки он светло-серый, без обложки — фирменные цвета.
- **Кнопка «играть/пауза» — полупрозрачная**, с белым значком: больше не выбивается из интерфейса.

## Что нового в 9.6

- **Окно источников — живое и без ожидания.** Открывается сразу, музыка при этом продолжает играть. ## Что нового в 4.7 — без пауз

## Что нового в 4.5 — бесшовный переход с фрагмента

- **Точность стыка — доли миллисекунды.** Место уточняется по форме звуковой волны, а не только по грубому «рисунку» (раньше точность была ±30 мс, этого хватало на слышную «запинку»).
- Полоса перемотки показывает настоящее время песни. Перемотка назад, раньше места стыка, тоже работает.
- Если полная версия нашлась в последние 3 секунды фрагмента или место не удалось найти уверенно — переход как раньше.

## Что нового в 4.4 — исправлено и ускорено

- **Нажатие на песню снова сразу её включает.** В 4.2 подготовка начиналась от каждого касания, даже при прокрутке. Десятки поисков забивали движок, и нажатая песня ждала в очереди. Теперь подготовка начинается, только если палец задержался на песне без прокрутки, и только для одной песни.

- **Главная открывается мгновенно.** Сначала показывается сохранённое с прошлого раза, затем подменяется свежим. Apple больше не задерживает экран (ждём не дольше 7 с), без сети показывается последнее сохранённое.

- **Быстрее поиск.** Ссылки для двух лучших вариантов берутся одновременно. Запасные площадки (Яндекс, Internet Archive и др.) опрашиваются, только если песни нет на основных.
- **С начала, а не с середины.** Фрагмент с середины песни играет, только если площадки не ответили за 6 секунд.

Выше ставит любимое (♥), часто слушаемое и песни любимых исполнителей. Радио тоже учитывает вкус: пролистанное не предлагает, любимых исполнителей ставит ближе к началу. ## Как пользоваться

Внизу три вкладки:

- **Скачать** — поле для ссылки (с кнопками «очистить» и «Вставить из буфера»). Под полем
  сразу видно, что это за ссылка: «TikTok · видео», «Spotify · альбом → MP3». Формат —
  переключатель **Видео | 720p | MP3** (для Spotify, Apple Music и т.п. доступен только MP3),
  большая кнопка **Скачать**. Для музыки — кнопка **Ссылки в других сервисах**.
  Если что-то качается, ниже видна карточка с прогрессом.
- **Загрузки** — разделены на **Все | Музыка | Видео**, а ниже — фильтр по сервисам
  (YouTube, TikTok, Spotify, Яндекс Музыка…, с количеством). В разделе «Музыка» есть
  **Слушать всё**. Дальше — у каждой загрузки прогресс, проценты, скорость и сколько осталось.
  Кнопки: «Отменить»; «Открыть», «Поделиться», «Удалить файл» — когда готово;
  «Повторить» — при ошибке. Готовое можно **смахнуть** в сторону, чтобы убрать из списка
  (появится «Вернуть»). «Очистить готовые» — вверху. На вкладке — счётчик активных загрузок.
- **Не нужно ждать конца загрузки.** Пока трек или видео качается, на карточке есть
  «Слушать сейчас» / «Смотреть сейчас» — играет прямо из интернета. У альбома — «Слушать
  готовое»: каждый трек сохраняется сразу, как только скачан.
- **Скорость.** Три ссылки качаются одновременно, треки альбома — по три сразу,
  каждый файл — в 4 потока. Самый быстрый формат музыки — «Оригинал» в Настройках
  (без перекодирования в MP3).
- **Ссылки у скачанных песен.** На карточке песни строка «Слушать в:» — установленные на
  телефоне сервисы выделены цветом (мой сервис первым). Нажали — песня находится в этом
  сервисе и открывается прямо в его приложении; ссылка запоминается. «Ещё» — экран
  «Где послушать» со всеми сервисами. В проигрывателе тоже есть «Где послушать».
- **Встроенный проигрыватель.** «Слушать»/«Смотреть» на карточке играет файл прямо в
  приложении. Музыка играет в фоне: мини-проигрыватель над нижней панелью, управление в
  уведомлении, на экране блокировки и с наушников (пауза при звонке и если выдернуть
  наушники). Очередь — вся музыка из текущего списка; есть перемешивание и повтор.
  Видео открывается на весь экран (можно повернуть телефон). Значок ↗ — открыть файл
  в другом приложении.
- **Обложки.** У каждой загрузки — обложка песни или кадр видео: пока качается — превью
  из источника, когда готово — из самого файла.
- **Тёмная тема** — по умолчанию. В Настройках → Оформление: тёмная, светлая или как в системе.
- **Настройки** — входы в аккаунты, файл cookies.txt, папка с файлами, версия и кнопка
  «Обновить движок».

Из любого приложения: **Поделиться → SoundAura** — снизу выезжает панель с форматом и кнопкой
«Скачать» (для видео через 8 секунд загрузка начнётся сама, если не выбирать формат).
Файлы лежат в **Загрузки/SoundAura**. На Android 12+ цвета приложения подстраиваются под обои.

## Вход в аккаунты

Нужен для Instagram, видео 18+ и приватных публикаций.

- **Войти в аккаунт** — выбираете сайт и входите во встроенном окне, как обычно.
- Google иногда не пускает во встроенные окна («Этот браузер небезопасен»). Тогда:
  **Загрузить файл cookies.txt** → войдите на сайт в Firefox (можно через Google),
  выгрузите вход дополнением «Get cookies.txt LOCALLY» и выберите этот файл.
  После этого удалите файл из «Загрузок».
- Входы хранятся только в закрытой папке приложения. «Выйти из всех аккаунтов» стирает их.

Для YouTube лучше входить запасным Google-аккаунтом: при частых скачиваниях
YouTube может временно ограничить аккаунт.

## Музыка

Spotify, Apple Music, Deezer, VK Музыка, Звук и Зайцев.нет не отдают сам звук (он зашифрован
или нужен вход). Поэтому приложение берёт название, исполнителя и длительность трека и ищет
его в открытых источниках по очереди:

1. **YouTube Music** (раздел «Песни») — официальные альбомные версии, без цензуры.
2. **SoundCloud** — если в YouTube Music не нашлось.
3. **YouTube** — в крайнем случае.

Из 6–8 результатов каждого источника приложение само выбирает лучший: тот же исполнитель
и название, длительность ±несколько секунд. Отсеиваются ремиксы, каверы, «slowed/sped up»,
nightcore, 30-секундные превью и версии с цензурой («clean», «radio edit»).
Теги (название, исполнитель, альбом) и обложка берутся из музыкального сервиса.

В **Настройках → Музыка**: «Качество» (MP3 — открывается везде; «Оригинал» — M4A/Opus
без перекодирования, чуть лучше звук) и «Где искать песни» (можно сначала SoundCloud).

- **Яндекс Музыка**: сначала пробуем оригинальный звук Яндекса, если не вышло — поиск выше.
  Через зарубежный VPN Яндекс не отвечает: отключите VPN или делитесь треком из приложения
  Яндекса — название придёт вместе со ссылкой, и этого хватит.
- **VK Музыка, Звук, Зайцев.нет** без входа не показывают треки — делитесь треком из их
  приложений: название придёт вместе со ссылкой.
- **Зайцев.нет** закрыт для зарубежных серверов, поэтому скачивать прямо с него приложение
  не умеет (не на чем было проверить) — он есть в трансфере как поиск.
- **Discord**: нужна ссылка на сам файл, а не на сообщение.

## Трансфер: песня из одного сервиса → ссылки во всех остальных

«Поделиться → **Где послушать**» (отдельный пункт в меню) или кнопка на главном экране.
Обложка, название и ссылки: Яндекс Музыка, Spotify, Apple Music, YouTube Music, VK Музыка,
Звук, YouTube, Deezer, SoundCloud, Зайцев.нет.

- **Приложения на телефоне.** SoundAura видит, какие музыкальные приложения установлены:
  они идут первыми с пометкой «установлено» и открываются сразу в приложении.
  Сверху — большая кнопка «Открыть в …» для **моего сервиса** (выбирается в Настройках,
  по умолчанию — первый установленный).
- **Точная ссылка** — Яндекс Музыка, Apple Music, Deezer, YouTube, YouTube Music.
  **Поиск в сервисе** — Spotify, VK Музыка, Звук, SoundCloud, Зайцев.нет (нет открытого поиска).
- **Поделиться** отправляет **карточку песни**: картинку (обложка, название, значки сервисов)
  и сообщение со всеми ссылками. Получателю не нужно ничего ставить — он просто открывает
  ссылку на свой сервис. Ссылки в сообщении читаемые (русские буквы не превращаются
  в %D0%9A…), сообщение укладывается в лимит подписи Telegram.
- **Копировать всё** — только текст со ссылками. **MP3** — скачать.

## Быстрый доступ

- В меню «Поделиться» два пункта: **SoundAura** (скачать) и **Где послушать** (трансфер).
- Android может показывать их и в верхнем ряду меню «Поделиться» как быстрые кнопки
  (это решает система — чаще, если приложением пользоваться).
- Долгое нажатие на значок приложения: **Скачать из буфера** и **Где послушать** —
  берут ссылку, которую вы скопировали.

## Обновления

yt-dlp внутри приложения сам обновляется раз в неделю — сайты часто меняются.

## Для разработчика

```bash
cd android-app
./gradlew assembleRelease   # APK в app/build/outputs/apk/release/
```
Сборка и публикация релиза — `.github/workflows/android.yml`.
APK подписывается ключом `app/signing.jks` (пароль в `app/build.gradle.kts`), чтобы обновления
ставились поверх. Ключ лежит в закрытом репозитории; если репозиторий станет публичным,
замените ключ и уберите его в секреты GitHub.

Скачивайте только то, что можно сохранять для личного использования.
