# SoundAura 6.3 — музыка без цензуры для Android

## Что нового в 9.59

- Прямые загрузки (hit.fm и другие серверы без токена) качаются кусками по 10 МБ в 4 потока — быстрее и без затыков.
- Обложки в списках теперь копятся и на диске (~60 МБ), не вымываются из памяти — меньше повторных загрузок.
- Сборка 205.

## Что нового в 9.58

- Журнал теперь пишет каждый переход: трек → источник → какой пункт сработал (кэш/догрузка/новый поток) и за сколько миллисекунд — с него сразу видно, где теряется время.
- Повторное нажатие на играющий трек ставит паузу, а не начинает трек заново.
- Сборка 204.

## Что нового в 9.57

- Сборка 203.

## Возможности

- **Поиск** по YouTube Music, ВК, Zaycev.net, Bandcamp и интернету.
- **Очередь** без пауз: следующий трек грузится заранее.
- **Загрузки** кусками по 10 МБ в 4 потока, продолжаются при смене сети.
- **Обложки** на диске (~60 МБ), не грузятся заново.
- **Текст песни** прямо на экране плеера.
- **Крутящийся диск** с обложкой на экране плеера.
- **История** прослушиваний и загрузок.
- **Журнал** переходов: видно, откуда пошёл трек и сколько заняло.

## Установка

1. Скачайте APK из раздела Releases.
2. Разрешите установку из неизвестных источников.
3. Установите и откройте SoundAura.

## Вход в ВК

1. Настройки → «Музыка из ВК».
2. Войдите в свой аккаунт.
3. Поиск и ссылки — как на m.vk.ru.

## Правила

- Писать по-русски, коротко, без оправданий.
- Цель: нажал — сразу играет полная версия в хорошем качестве.
- Не гадать. Правки поиска и проигрывания — только по журналу с телефона.
- APK собирать и присылать, когда правка готова к проверке.

## Запрещено

- Пиратские сайты и боты с музыкой из ВК (только через свой аккаунт).
- Вытаскивание звука из Spotify.
- Управление Spotify.
- Чужие ключи Telegram.

## Лицензия

Скачивайте только то, что можно сохранять для личного использования.
