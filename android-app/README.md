# Загрузчик — приложение для Android

Поделились ссылкой → получили файл. Без рекламы. Плюс **трансфер музыки**: прислали песню
в одном сервисе — получаете ссылки на неё во всех остальных.

**Видео:** YouTube, TikTok, VK (видео и клипы), X/Twitter, Instagram, Snapchat Spotlight,
Яндекс Видео, Дзен, Rutube, Одноклассники, Reddit, Pinterest, Twitch-клипы, файлы из Discord
и ещё около 1800 сайтов. Внутри — [yt-dlp](https://github.com/yt-dlp/yt-dlp) и ffmpeg.

**Музыка (MP3):** Spotify, Яндекс Музыка, Apple Music, Deezer, VK Музыка, YouTube Music, SoundCloud.

## Установка

1. Скачайте APK:
   - **Zagruzchik-arm64.apk** — для почти всех телефонов (2017 года и новее);
   - **Zagruzchik-old-phones.apk** — только если первый не ставится.

   Где взять: GitHub → репозиторий → **Releases** → «Загрузчик (последняя версия)».
   Новая сборка появляется там автоматически после каждого изменения кода.
2. Откройте файл на телефоне и разрешите установку из этого источника.
3. Запустите «Загрузчик» один раз и разрешите уведомления.

Нужен Android 10 или новее.

## Как пользоваться

- В YouTube, TikTok, Instagram, Spotify и т.д.: **Поделиться → Загрузчик**.
  Выберите «Видео», «Видео 720p» или «Только звук MP3». Если ничего не выбрать,
  через 8 секунд загрузка начнётся сама (для музыки — MP3, для остального — видео).
- Или откройте приложение: ссылка из буфера обмена подставится сама.
- После выбора формата открывается приложение со списком **Загрузки**: у каждой загрузки
  прогресс-бар, проценты, скорость и сколько осталось. Альбомы Spotify показывают «трек 7/18».
- Кнопки в карточке: **Отменить** во время загрузки; **Открыть**, **Поделиться**,
  **Удалить файл** и **✕** (убрать из списка) — когда готово; **Повторить** — при ошибке.
  «Очистить готовые» убирает из списка всё завершённое (файлы остаются).
- У поля ссылки есть **✕** (очистить) и **Вставить**. Уже скачанные ссылки из буфера обмена
  сами больше не подставляются.
- Закрывать приложение можно: загрузка идёт в фоне. Android при этом показывает одно тихое
  уведомление «Скачиваю…» — так требует система. Все файлы лежат в **Загрузки/Загрузчик**.

## Вход в аккаунты

Нужен для Instagram, видео 18+ и приватных публикаций.

- **Войти в аккаунт** — выбираете сайт и входите во встроенном окне, как обычно.
- Google иногда не пускает во встроенные окна («Этот браузер небезопасен»). Тогда:
  **Загрузить файл cookies.txt** → войдите на сайт в Firefox (можно через Google),
  выгрузите вход дополнением «Get cookies.txt LOCALLY» и выберите этот файл.
  После этого удалите файл из «Загрузок».
- Входы хранятся только в закрытой папке приложения. «Выйти из всех аккаунтов» стирает их.

Для YouTube лучше входить запасным Google-аккаунтом: при частых скачиваниях
YouTube может временно ограничить аккаунт.

## Музыка

Spotify, Apple Music, Deezer и VK Музыка не отдают сам звук (он зашифрован или нужен вход).
Поэтому приложение берёт название, исполнителя и длительность трека и скачивает этот же трек
с YouTube в MP3. Из первых пяти результатов выбирается тот, что совпадает по длительности,
чтобы не попадались часовые версии и клипы. Теги MP3 (название, исполнитель, альбом) берутся
из музыкального сервиса. Альбомы и плейлисты сохраняются в отдельную папку.

- **Яндекс Музыка**: сначала пробуем оригинальный звук Яндекса, если не вышло — YouTube.
  Через зарубежный VPN Яндекс не отвечает: отключите VPN или поделитесь треком из приложения
  Яндекса — название придёт вместе со ссылкой, и этого хватит.
- **VK Музыка** без входа не показывает треки, поэтому делитесь треком прямо из приложения VK:
  название придёт вместе со ссылкой.
- **Spotify**: плейлисты — первые 50 треков. **Apple Music**: треки и альбомы.
- **Discord**: нужна ссылка на сам файл (нажмите на вложение → «Копировать ссылку»), а не на сообщение.

## Трансфер: песня из одного сервиса → ссылки во всех остальных

«Поделиться → Загрузчик» → **🔗 Ссылки в других сервисах** (или кнопка на главном экране).
Приложение узнаёт трек и показывает обложку и ссылки: Яндекс Музыка, Spotify, Apple Music,
YouTube Music, VK Музыка, YouTube, Deezer, SoundCloud. У каждой — «Открыть» и «Копировать»,
внизу — «Поделиться всеми ссылками», «Копировать всё» и «Скачать MP3».

- **Точная ссылка на трек** — Яндекс Музыка, Apple Music, Deezer, YouTube и YouTube Music:
  у них есть открытый поиск, и трек сверяется по названию, исполнителю и длительности
  (ремиксы, каверы и «sped up» отсеиваются).
- **Поиск в сервисе** — Spotify, VK Музыка, SoundCloud: у них нет открытого поиска без ключей,
  поэтому ссылка открывает поиск этого трека в приложении сервиса.
- Если точный трек не нашёлся, вместо ссылки на трек тоже будет поиск.
- Для альбомов и плейлистов — ссылки на поиск альбома во всех сервисах.

## Обновления

yt-dlp внутри приложения сам обновляется раз в неделю — сайты часто меняются.

## Для разработчика

```bash
cd android-app
./gradlew assembleRelease   # APK в app/build/outputs/apk/release/
```
Сборка и публикация релиза — `.github/workflows/android.yml`.
APK подписывается ключом `app/signing.jks` (пароль в `app/build.gradle.kts`), чтобы обновления
ставились поверх. Ключ лежит в закрытом репозитории; если репозиторий станет публичным,
замените ключ и уберите его в секреты GitHub.

Скачивайте только то, что можно сохранять для личного использования.
