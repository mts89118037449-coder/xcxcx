# Зона — тюремная RPG для Telegram Mini App

Браузерка в жанре «тюремной» RPG из ВК, сделанная как Telegram Mini App. Весь игровой контент
(названия, баланс, тексты) свой, поэтому игра не завязана на чужой бренд.

**Что есть в игре**

- **Прогрессия:** уровни, опыт, три навыка (сила, ловкость, выносливость). Очки навыков за уровень и тренировки за деньги.
- **Работа:** 7 работ, тратят энергию. Энергия восстанавливается со временем.
- **Шмот:** 6 слотов, вещи за рубли и за золото, редкие трофеи с боссов.
- **Наколки:** постоянные бонусы, требуют уровень и авторитет.
- **Боссы:** 4 босса с откатом и шансом дропа.
- **Онлайн:**
  - общий босс «Бунт на централе»: его бьёт весь сервер, награда делится по урону;
  - PvP-наезды на живых игроков своего уровня (если подходящих нет, против бота);
  - рейтинг авторитета, счётчик онлайна.
- **Графика и анимации (полуреалистичная манера, всё нарисовано в SVG):**
  - персонаж собирается из слоёв: надетые шмотки, обувь, шапки, оружие и талисманы рисуются прямо на нём;
  - наколки появляются на коже (кнопка «Показать наколки» снимает верх);
  - руки растут вместе с силой, при низком здоровье появляются фингал и пластырь;
  - персонаж с нормальными пропорциями: объём градиентами, мышечный рельеф, щетина, складки одежды;
  - персонаж дышит и моргает;
  - фактура в сценах: грязные стены, сколы краски, свет из окна, зерно и виньетка;
  - вещи в магазине и инвентаре показаны картинками в той же манере, без эмодзи;
  - локации: Хата, Промзона, Двор. Меняется время суток в окне, мигает лампа, по конвейеру едут ящики,
    летят искры, ходит прожектор на вышке, клюёт ворона;
  - бои проигрываются удар за ударом: выпад, отдача, цифры урона, крит, нокаут;
  - боссы нарисованы тем же конструктором (вертухай, начкар, хозяин зоны).
- **Обустройство хаты:** 15 предметов мебели (матрас, одеяло, ковёр на стену, иконостас, тумбочка,
  стол с чифирбаком, радио, телевизор, аквариум, холодильник…). Всё купленное видно в сцене камеры и даёт бонусы.
- **Редактор персонажа:** лицо (32 варианта), телосложение, цвет кожи, имя (первая смена бесплатно).
- **Хата:** отделка стен и пола (9 вариантов, часть за золото) плюс 15 предметов мебели.
- **Дейлики:** 3 случайных задания на день, одинаковые весь день, сброс в полночь МСК, бонус за все три.
- **Поручения:** доска из 3 случайных заданий с таймером (5–60 мин), шансом провала, ускорением и сменой доски за золото.
- **Кланы:** создание (с 5 уровня), вступление, общак, прокачка до 10 уровня (+3% денег и +2 энергии за уровень всем),
  выгнать участника, передача главенства при уходе.
- **Соседи:** можно зайти в хату любого игрока из рейтинга или клана и «уважить» его (+1 авторитета, раз в день).
- **Энергия:** таймер до +1 и до полной, покупка +30 или полной за золото, чифир как запас, пак чифира за звёзды.
- **Ежедневный бонус** с серией и **реферальная система** (обоим игрокам по 50 золота).
- **Донат в Telegram Stars:**
  - пакеты золота;
  - VIP «Блатной статус» (x2 энергия, +20% денег, золото каждый день);
  - разовый стартовый набор.

## Как тебе платят

Цифровые товары в Telegram разрешено продавать только за **Telegram Stars** (валюта `XTR`), и игра
работает именно так. Платёжный провайдер не нужен.

1. Игрок жмёт покупку в «Ларьке». Сервер создаёт счёт (`createInvoiceLink`), Telegram показывает окно оплаты.
2. Telegram присылает `pre_checkout_query`. Сервер проверяет товар и цену.
3. Telegram присылает `successful_payment`, и сервер зачисляет покупку. Каждый платёж зачисляется ровно один
   раз: повторная доставка того же платежа ничего не начислит.
4. Звёзды копятся на балансе бота. Вывести их можно в TON через [Fragment](https://fragment.com):
   @BotFather → твой бот → *Payments / Stars balance*. Звёзды становятся доступны к выводу примерно
   через 21 день после покупки.

Команды `/paysupport` и `/terms` Telegram требует от ботов с платежами, они уже есть.
Команда `/stats` показывает админам число игроков, онлайн и выручку в звёздах.

Цены и содержимое пакетов меняются в `shared/content.ts` → `STAR_PACKS`.

## Запуск

Нужен Node.js **22.18+**: база — встроенный `node:sqlite`, TypeScript запускается без сборки.

```bash
cd zona
npm install
npm run build          # собрать фронтенд в dist/
cp .env.example .env   # заполнить BOT_TOKEN, PUBLIC_URL, ADMIN_IDS
npm start              # сервер: API + webhook + статика на PORT (8080)
```

**Настройка бота:**

1. Создай бота в [@BotFather](https://t.me/BotFather) и положи его токен в `BOT_TOKEN`.
2. Разверни сервер на HTTPS-домене (VPS + nginx/Caddy, Render, Railway и т.п.) и укажи его в `PUBLIC_URL`.
3. При старте сервер сам ставит webhook `PUBLIC_URL/tg/webhook` с секретом и кнопку меню «Играть».
4. По желанию: в BotFather → *Bot Settings → Configure Mini App* укажи тот же URL. Тогда игра открывается по
   ссылке `t.me/<бот>/app`.

База лежит в `data/zona.db` (или в `DB_PATH`). Её нужно бэкапить: там игроки и история платежей.

### Установка на свой сервер одной командой

Ubuntu/Debian, от root. Скрипт `deploy/install.sh` ставит Node.js 22 и Caddy, забирает код, собирает фронтенд,
кладёт секреты в `/etc/zona.env` (права 600), запускает сервис `zona` (systemd), получает HTTPS-сертификат
и ставит ночной бэкап базы в `/var/lib/zona/backups` (14 дней). Домен по умолчанию —
`<ip-через-дефисы>.sslip.io`: он бесплатно указывает на IP сервера, и на него выдаётся настоящий сертификат,
который требует Telegram. Свой домен — через `DOMAIN=...`.

```bash
# репозиторий приватный: нужен токен GitHub с доступом только на чтение (Contents: Read-only)
export GIT_TOKEN=github_pat_...
curl -fsSL -H "Authorization: Bearer $GIT_TOKEN" \
  https://raw.githubusercontent.com/mts89118037449-coder/xcxcx/claude/tyuryaga-telegram-port-jignpo/zona/deploy/install.sh -o install.sh
BOT_TOKEN='токен от BotFather' ADMIN_IDS=<твой telegram id> DOMAIN=<ip-через-дефисы>.sslip.io bash install.sh
```

Обновление — тот же `bash /opt/zona/zona/deploy/install.sh` (с `GIT_TOKEN`): токен бота и админы берутся из
`/etc/zona.env`. Логи: `journalctl -u zona -f`. При старте сервер сам ставит webhook, кнопку «Играть»,
команды и описание бота. Админам из `ADMIN_IDS` доступна `/stats`, приходят уведомления о покупках и
обращения из `/paysupport`.

### Локальная разработка без Telegram

```bash
npm run dev:server   # сервер с DEV_AUTH=1 (вход без подписи Telegram)
npm run dev          # Vite на :5173 с прокси /api
# открыть http://localhost:5173/?dev=1   (?dev=2 — второй игрок и т.д.)
```

`DEV_AUTH=1` пропускает любого игрока без подписи Telegram, поэтому на проде его включать нельзя.

### Проверки

```bash
npm test       # логика игры + API: подпись initData, платежи, PvP, общий босс
npm run lint   # tsc --noEmit
npm run sim    # симуляция экономики: казуал, активный, задрот — прогресс, боссы, золото по дням
```


### Нестандартный порт HTTPS (если 443 занят, например VPN)

```bash
HTTPS_PORT=8443 bash /opt/zona/zona/deploy/install.sh
```

Скрипт соберёт Caddyfile с `https_port 8443` и блоком `домен:8443`, запишет `PUBLIC_URL=https://домен:8443` и
`HTTPS_PORT=8443` в `/etc/zona.env`. Бот берёт этот адрес для webhook и кнопки «Играть». Дальше порт запоминается —
при обновлении передавать не нужно; если его нет в `/etc/zona.env`, берётся из текущего `/etc/caddy/Caddyfile`.
Порт 80 должен быть свободен (по нему Let's Encrypt проверяет домен), Telegram принимает webhook только на 443/80/88/8443.
Свой Caddyfile скрипт не трогает, если в нём есть строка `# zona: manual`.

`GIT_TOKEN` для приватного репозитория достаточно передать один раз: он сохраняется в `/root/.zona-git-credentials`
(права 600), а не в адресе репозитория, и потом `install.sh` и `git pull` в `/opt/zona` работают без логина.

## Устройство

```
shared/content.ts   весь контент и баланс: вещи, наколки, работы, боссы, донат-пакеты
shared/types.ts     типы ответа API
server/game.ts      игровая логика (чистые функции, покрыты тестами)
server/app.ts       HTTP API, webhook бота, приём платежей
server/db.ts        SQLite
server/auth.ts      проверка подписи Telegram initData
src/                клиент на React
src/art/            SVG-графика: риг персонажей (rig/), локации (Scenes.tsx), мебель (CellDecor.tsx), арена боя
scripts/sim.ts      симуляция экономики по дням (npm run sim)
tests/              node:test
```

Сервер — единственный источник правды. Клиент только отправляет действия (`/api/action/<тип>`), а все
расчёты (бои, награды, энергия, покупки) делает сервер. Поэтому накрутить золото или ресурсы через клиент
нельзя.

API ограничивает частоту запросов на игрока (ведро на 40 запросов, +8 в секунду): живой игрок в него не упрётся,
а скрипт, долбящий мини-игры, получит 429 и не положит сервер.

### Масть, срок и ходки

**Этапирование.** Новичок начинает не с меню, а с пяти сцен с выбором: автозак, шмон на приёмке, хата и дед
Митрич, первая прогулка и стычка с качком, ночной разговор. Ответы дают немного денег, авторитета, опыта или
бычков, в конце — бинт и песок для первой драки (`shared/term.ts`, `src/Intro.tsx`).

**Масть** выбирается с 5 уровня: блатной (добыча в наездах, авторитет, крит), мужик (деньги и опыт со смен,
энергия), активист (поручения, быстрые откаты боссов, но меньше авторитета), отрицала (атака, крит, награда за
побег). Сменить можно за 100 🪙 и 30% авторитета.

**Срок до УДО.** У каждой ходки свой срок (180 дней, каждая следующая на 60 длиннее). Его скашивают потраченная
энергия, победы над боссами и в наездах, дела дня, шаги сюжета и случаи; пойманный в побеге получает довесок.
По симуляции активный игрок выходит примерно за месяц, спокойный — за два. **Выход по УДО** начинает уровень,
навыки и деньги заново, но шмот, наколки, хата и золото остаются, а каждая отсиженная ходка навсегда даёт +10% к
деньгам и опыту (до +100%) и золото на выходе. Вещь работает только с её уровня — старый шмот ждёт, пока
дорастёшь.

**Неделя грева:** семь дней подряд с разными наградами (деньги, бычки, бинт, чифир, свинчатка), на седьмой —
большой грев с 10 🪙; пропуск дня обнуляет серию.

**Напоминания от бота** (`runNotifier`, раз в 10 минут): грев пришёл, энергия полная, ждёт случай, босс
оклемался, срок вышел; «на тебя наехали» — сразу после наезда. Не больше трёх в день, с 23 до 9 по Москве бот
молчит, каждое напоминание — не чаще раза между заходами, давно не заходивших не беспокоим. Выключаются в профиле.

### Баланс

`npm run sim [дней]` гоняет трёх ботов по настоящим серверным правилам — казуал (3 захода в день), активный (8) и
задрот (16), без доната — и печатает уровень, деньги, золото, силу, лучшего побеждённого босса, победы/попытки по
каждому боссу, доходы и траты и откуда пришло золото. По нему сейчас: восемь боссов растягиваются примерно на два
месяца (казуал бьёт «Хозяина зоны» к ~20-му дню, активный доходит до «Спецназа „Тайфун“» к ~60-му); бесплатный
игрок получает ~10–25 🪙 в день (грев по кругу 1…7 дней, золото с босса — только за первую победу в сутки); кости,
очко, бега и напёрстки в среднем в пользу заведения; главный поглотитель денег в поздней игре — качалка.

### Персонажи: кукла на скелете

Все персонажи — герой, соперники, сокамерники, НПС и боссы — рисуются одним ригом (`src/art/rig/Rig.tsx`,
cutout-анимация в SVG). Тело разбито на части (торс, таз, шея, голова, плечо, предплечье, кисть, бедро, голень,
стопа), каждая повёрнута вокруг своего сустава. У конечности сначала рисуется общий контур всех её частей, потом
заливка и светотень — поэтому на локтях и коленях нет швов. Конечности строятся по анатомическому профилю
(дельта, бицепс, предплечье, квадрицепс, колено, икра), у каждой части своя cel-тень со стороны от света
(обрезается по контуру части) и блик спереди; на ткани тень со штриховкой. Голова вполоборота: профиль носа,
губ и подбородка на контуре, дальний глаз меньше, глазницы, скулы и ухо; кисти с пальцами и костяшками кулака,
стопы с пяткой и пальцами, на торсе грудные, пресс и ключицы — прорисовка сильнее с ростом силы.

Одежда описана не картинками, а свойствами (`src/art/rig/wear.ts`): цвет, фактура (полоска, камуфляж, стёганка,
пуховик, джинса, мешковина, мех), длина рукава, воротник, подол, молния, пуговицы, погоны, лямки, фартук. Она
рисуется поверх тех же частей тела и двигается вместе с ними, поэтому любая вещь садится на любую позу:
стоя, сидя на табурете, при ходьбе, беге, работе, в стойке, при ударе, получая удар, в нокауте, радуясь. Шапки
надеваются на голову, оружие — в руку, чётки и печатка — на кисть, цепура — на шею, наколки — на кожу и видны,
только если не закрыты одеждой. Внешность собирается из частей: 8 причёсок × 6 бород × 3 формы лица × 2 вида
бровей, плюс телосложение (толщина торса и рук растёт и с силой) и цвет кожи. Портреты в шапке и списках — та же
голова рига. НПС описаны в `src/art/rig/npcs.ts`. Отладка всех поз и вещей: `/?rig=1`.

Анимаций 28: стойка, ходьба, бег, сидя, работа, удар рукой и ногой, уклон, получил удар, нокаут, радость,
насмешка, затяжка сигаретой (с дымом), чай из кружки, еда из миски, раздумье, потягивание, помахать, «двойной
бицепс», мёрзнет, приседания, отжимания, сон (с «z-z-z»), танец, турник и др. Стоящий без дела персонаж сам иногда
закуривает, пьёт чай или потягивается — у каждого своё расписание, поэтому толпа живая. В бою удары чередуются
руками и ногами, промах — уклон, проигравший падает в нокаут. Отладка: `/?rig=1` (можно `&anim=` и `&t=мс` —
застывший кадр).

Наколки (`src/art/rig/tattoos.tsx`) — отдельные рисунки со своим местом на теле: купола и орёл на груди, звёзды
под ключицами, погоны на плечах, паук, тигр, роза, кот, череп и кинжал раскладываются по плечам и предплечьям,
перстни — на пальцах. Иконки наколок в салоне — те же рисунки.

**Хата.** У каждого из 12 мест (шконка, стена, свет, техника, стол, пол, окно, угол, спорт, живность, музыка, декор) — лестница из
3–6 ступеней: от облезлой штукатурки и лампочки на шнуре до персидского ковра, хрустальной люстры и гигантской
плазмы с приставкой. Следующая ступень покупается только после предыдущей, бонусы всех купленных складываются,
а в сцене стоит выбранная — можно вернуть голые стены. Уют хаты (сумма ступеней) видно в гостях. Музыка: гитара с
бантом и баян на шконке, магнитофон «Весна» с крутящимися катушками и музыкальный центр с эквалайзером под ней.
Декор под потолком: бельё на верёвке, вымпелы «Спартак», часы с кукушкой (маятник качается), оленьи рога. В
живности появился пёс Мухтар — дремлет у шконки и виляет хвостом.

**Рандом и события.** Каждые 12–30 минут на зоне что-то случается (больше сотни случаев: шмон, карты с блатным,
письмо от мамы, передачка, кольщик…) — мигает «❗», персонаж предлагает выбор, исход решает жребий. Во дворе можно
прогуляться раз в полчаса — случай сразу. На промке бывает премия ×2 и находки.
- **Цепочки** (`shared/events_more.ts`): исход с `next` ведёт к продолжению через `EVENT_TIMING.chainMin` минут —
  малява в третий барак, долг Сявы, опер вербует, брага в цеху, почтовый голубь, первоход, письмо матери,
  карточный долг, подкоп под баней. Продолжения помечены `chain: true` и сами не выпадают.
- **Условия:** `mast` — случай только для масти, `night` — только ночью по Москве, `minLevel`, `need` — например,
  с наколкой. У варианта ответа `need: { mast | tattoo | level | authority }` — чужой вариант виден, но закрыт.

**Силы зоны и общак** (`shared/factions.ts`, вкладка «Зона → Люди»). Репутация у братвы (наезды, общак, грев в
ШИЗО), работяг (смены, промка) и администрации (поручения, церковь, библиотека, клуб). Своя масть растит быстрее
(×1.5), братва и администрация — соперники: плюс одним — минус другим. Шесть званий, каждое даёт % к добыче /
сменам / поручениям; третье открывает особое (помощь из общака, срок быстрее). Воровской общак один на всю зону
(таблица `kv`): уделил — растёшь у братвы, близким раз в сутки помогает.

**Долги.** У барыги можно занять 5/10/20 паек под 20% на сутки (не больше 2 паек на уровень). Катала играет «под
запись» — проигрыш становится долгом. Просрочка — счётчик: +15% в сутки, минус авторитет и репутация у братвы; на
третьи сутки долг выбивают силой (забирают деньги и полздоровья). Должнику приходит сборщик.

**Ремесло** (`shared/craft.ts`, «Шмот → Ремесло»). Восемь материалов (нитки, тряпьё, обрезки, мякиш, чай,
проволока, тушь, лезвие) — с промки, кухни, библиотеки, свиданки, смен и боссов. 17 рецептов: расходники (бинты,
заточки, самогон, малява…) и четыре талисмана, которых нет в ларьке. «Мастеровой» у работяг получает материалов вдвое.

**Барахолка** («Зона → Рынок», таблица `market`). Игроки выставляют расходники, материалы и неснятый шмот (до 5
лотов), назначают цену; покупка — деньги продавцу, 5% в воровской общак. Улучшения вещи при продаже сгорают.

**Ещё семь мини-игр** (`shared/minigames2.ts`, `src/Minigames2.tsx`). С сервером: нарды с цыганом (гонка до 24-й
клетки с ловушками и мостиками), домино со стариком (цепочка, базар, «рыба»), шахматный этюд — мат в один ход
(свой проверщик ходов засчитывает любой матующий). На ловкость, клиент присылает результат, сервер режет: чифир на
скорость (реакция), конвейер (снимай брак — деньги и работяги), чётки (в такт — силы и опыт), рыбалка из окна
«конём» (грев, материалы, бычки).

**Выжить в ШИЗО** (раз в день, с 4 ур.): пять суток, три шкалы — тепло, сытость, дух. Каждый день ситуация с
выбором (некоторые с риском), каждую ночь −1 ко всему, ноль по любой шкале — сломался и в санчасть. Выжил —
авторитет, братва, опыт и полдня срока. Баланс проверен симуляцией: с умом выживают ~85%, наугад ~50%.

**Кланы: хата, босс, война** (`shared/clans.ts`, «Бой → Братва → Кланы»). Хата клана — четыре постройки до 5 уровня
(кухня +энергия, качалка +атака, касса +деньги, стрёма +защита), строит главный из общака клана. Босс клана — новый
каждый день, толщина по числу участников и уровню; добили — деньги по доле урона, золото каждому, доля в общак.
Война кланов — недельная таблица очков (наезды, боссы, бунт, босс клана); топ-3 забирают золото и деньги в общак.
Состояние клана и таблицы войны — в `kv` (`clan:<id>`, `clanwar:<неделя>`).

**Ринг** («Бой → Ринг», `kv` `ring`). Живые бои по очереди: вышли двое — через 2 минуты бой, пока идёт отсчёт,
зрители ставят на бойцов. Бойцы бьются в полную силу, победитель забирает оба взноса и авторитет. Тотализатор:
угадавшие делят банк проигравших пропорционально ставке, 10% — на общак. Прошлые бои можно пересмотреть.

**Чат барака** («Бой → Братва → Чат», таблица `chat`). Только готовые фразы из `shared/chat.ts` (привет, дела,
клан, эмоции) — модерация не нужна. Два канала: весь барак и свой клан. Не чаще раза в 8 секунд и 80 фраз в день.
Нажал на лицо в чате — зашёл к человеку в хату.

**Грев и кенты.** В чужой хате — «Грев посылкой»: расходник или материал из своих запасов, 3 посылки в день, получателю
приходит сообщение от бота. Деньги не шлются — чтобы не качать твинков. Цепочка кентов: подтянутый дорос до 5/10/20
уровня — тому, кто подтянул, 20/40/80 золота, а тому, кто подтянул его, — 25% сверху. Список своих кентов — в «Братве».

**Сезоны и косметика** (`shared/season.ts`, кнопка ⭐ сверху). Каждый месяц — свой сезон с темой (Этап, Бунт,
Промзона, Большой шмон, Воровской сход, Зимовка): за дело темы очки сезона ×2. Пропуск на 30 уровней по 200 очков:
бесплатная дорожка — всем, платная (250 ⭐) — золото, чифир, рамка и титул сезона, на 30-м «Знак сезона». По симуляции
казуал за месяц берёт ~18 уровней, активный — все 30 к концу месяца. Рейтинг сезона, предложение дня (по кругу,
раз в день), косметика за Stars: рамки аватара (видны в шапке, чате, рейтинге) и титулы в чате. Новый месяц —
очки и пропуск с нуля, косметика остаётся.

**Хата: 16 мест и стиль.** К шконке, стене, свету и прочему добавились полка, плитка, нычка и фото (по 4 ступени).
Стиль хаты (`CELL_THEMES`): «Как дома», «Качалка», «Изба-читальня», «Святой угол», «Музыкальная», «Блатная» —
если в сцене стоят вещи одного стиля (4–5 групп), хата даёт бонус сверху. Считается именно то, что выставлено.

**Сюжет** (`shared/story.ts`): 12 глав — от «Первой ходки» до «Последнего звонка». Седьмая глава «Своя дорога»
у каждой масти своя (`variants`): блатной идёт «Воровским ходом», мужик — «Золотыми руками», активист — в «Совет
отряда», отрицала — в «Отрицалово». `chapterOf(ch, mast)` отдаёт нужную версию и серверу, и клиенту.

**Места зоны** (`shared/places.ts`, сцены в `src/art/Locations.tsx`): столовая, баня, библиотека (с 3 ур.), клуб
(с 5), промка (с 2), свиданка (с 8), ШИЗО (с 4). У каждого места хозяин и 4 занятия со своим откатом: пайка и
добавка, парилка и веник, ходатайство (может скостить срок), концерт самодеятельности, литейка, длительное
свидание за золото, грев в ШИЗО. Часть занятий только для масти или с авторитетом/уровнем. Экшен `place`.

**Побег.** Девять этапов (подкоп, двор, прожектор, собаки, колючка, забор, тайга, трасса, вокзал), на каждом —
мини-игра «поймай момент» или «жми быстрее», от точности зависит шанс. Сбежать нельзя: на вокзале ловят всегда.
Чем дальше ушёл, тем больше денег, опыта и авторитета; пойман — побои и ШИЗО на 6 ч, вернулся сам — 60% награды.

**Санчасть.** Койка лечит бесплатно раз в 90 мин, укол — за деньги, капельница — за золото, справка
«освобождение от работ» — раз в день, как повезёт.

**Гости.** «Обход бараков» на зоне ведёт по случайным хатам подряд: уважить, подогреть бычками или пошарить
(3 раза в день — заначка, пусто или хозяин застал; кот и попугай поднимают шум).

**Бой — пошаговый, с управлением.** Каждый ход игрок выбирает: 👊 удар, один из активных перков (у каждого —
перезарядка в ходах, счётчик на кнопке) или расходник с пояса (не тратит ход). Пассивные перки работают сами,
«Фото мамы» и «Не дождётесь» срабатывают при смертельном ударе. Противник ходит сам. «⏩ Авто» доводит бой до
конца, бой переживает перезапуск приложения (`server/combat.ts`: состояние боя — JSON у игрока).

**Режим бога для админа.** Игроки из `ADMIN_IDS` видят ⚙️ рядом с уровнем: переключатель «👤 Игрок / ⚡ Бог»
(в режиме бога деньги, золото, энергия и здоровье бесконечны, откаты сброшены; при выключении ресурсы
возвращаются как были) и инструменты: уровень, вся мебель, весь шмот, +10 расходников, запуск любого случая,
сброс боя, «стать новичком».

**Интерфейс.** Внизу пять разделов: Хата, Зона, Работа, Бой, Шмот. «Братва» (рейтинг и кланы) — вкладка внутри
«Боя», Ларёк — кнопка ⭐ в шапке. Шапка компактная: лицо с уровнем, короткий кошелёк (12,4к ₽), здоровье, энергия и
опыт в одну строку. Сцены во всю ширину и выше (края кадра обрезаются, карта зоны — целиком). Каждый экран делится
на разделы переключателем с иконками, выбор запоминается: Хата — сюжет, облик, обустроить, профиль; Зона — игры,
места, неделя; Работа — смены, поручения, дела дня, качалка; Бой — боссы, наезд, бунт, братва. Портреты НПС,
боссов, сюжета и рейтинга крупнее; ждущее событие — круглый портрет с «!» над меню.

**Досуг без энергии.** На зоне и в окне энергии — плитки занятий с остатком на сегодня: 🃏 очко с блатным
(ставка деньгами), 🪳 тараканьи бега (ставка бычками, фаворит чаще, но платит меньше), ☕ сварить чифир
(мини-игра на момент, +2…8 энергии, 4 раза в день), напёрстки, 🎲 кости с цыганом (ставка деньгами, дубль
при победе — втрое), 💪 армрестлинг (жми кнопку быстрее, чем давит соперник: тощий, работяга или качок; сила
даёт фору), 🎯 заточка в мишень (три броска, прицел гуляет всё быстрее, очки идут в бычки); места — двор, по
хатам, турник, церковь, санчасть, побег. Энергия нужна
для работы, драк, поручений и побега — без неё всегда есть чем заняться, но с ней быстрее.

**Сюжет.** Шесть глав («Первая ходка», «Свой среди своих», «Подкоп», «Смотрящий», «Масть», «Цыганское счастье») по 5–6 шагов: шаги
двигаются обычными действиями (смены, бычки, случаи, драки, мини-игры, гости, церковь, побег), за каждый —
награда. Карточка текущего шага с персонажем — на «Хате». Случаев на зоне — 31, выпадают каждые 12–30 минут.

**Примерка мебели.** Нажатие на вещь в «Обустроить» ставит её в хату на сцене до покупки — видно, как будет
выглядеть и что даёт; купить можно прямо с плашки на сцене.

**Перки и расходники.** В бою работают до 3 перков из 100 (`shared/perks.ts`): 12 типов по 8 ступеней
(точный удар, оглушение, второе дыхание, двоечка, глухая защита, заточка-кровотечение, ломка, кровопийца,
уклон, встречка, ярость, добивание) и 4 легендарных с 40+ уровня. Ступени открываются с уровнем, одного типа —
только один. У активных — перезарядка в ходах, пассивные действуют всегда, добивание — раз за бой. Сила
ступеней выровнена симуляцией: I ступень ≈ +5% к силе бойца, VIII ≈ +15%, легендарные ≈ +15–20%.
Боссы и боты тоже ходят с перками по своему уровню. На поясе — 3 расходника из 20: срабатывают в бою один раз
(лечение при низком здоровье, «Фото мамы» поднимает после смертельного удара, песок в глаза, соль в карман…)
и списываются. Покупаются в разделе «Шмот → Перки», выпадают с боссов (40%), в наездах (12%), за поручения
(35%), дела дня и недельные ступени; святую воду даёт батюшка на исповеди. Бой считается на сервере
(`server/combat.ts`), клиент проигрывает запись: урон, лечение, промахи и всплывающие названия перков.

**Зона и мини-игры.** Вкладка «Зона» — общий вид тюрьмы: здания ведут на экраны, по земле со временем появляются
бычки (новая валюта, 1 за 4 мин, максимум 8, иногда пачка на 5). Барыга меняет бычки на деньги, энергию, чифир
и золото. Сокамерники в сценах кликабельны и разговаривают: Лёха зовёт в напёрстки (честные 1 к 3, выплата 2.7×,
до 25 партий в день), дед отдаёт грев и травит байки, амбал во дворе провоцирует на наезд, бригадир на промке
даёт смену, лепила в санчасти лечит.

**Неделя.** Каждую неделю (с понедельника по МСК) — своё событие: бунт (урон ×2), шмон (деньги с боссов ×1.5),
слухи об амнистии (энергия быстрее), табачный кризис (бычки ×2), турнир (авторитет ×2). У события цель в три
ступени с наградами — деньги, золото, чифир.

**Без энергии.** Когда энергии не хватает, открывается окно пополнения (чифир, золото, звёзды) и список
бесплатных занятий: бычки на зоне, церковь (молитва — благодать +10% денег и +3% крита, свечка за бычки,
исповедь лечит), турник во дворе (мини-игра на скорость тапа, опыт), напёрстки, разговоры.

Вся графика нарисована кодом (SVG): персонажи — риг, фоны и мебель — сцены. Растровых картинок в игре нет,
сборка весит около 600 КБ, редкие окна (мини-игры, побег, церковь, санчасть, гости, админка) грузятся по
требованию, React — отдельным файлом, который остаётся в кеше между обновлениями.

### Как добавить вещь, наколку или мебель

1. Добавь запись в `shared/content.ts` (`ITEMS`, `TATTOOS` или `FURNITURE`).
2. Одежду опиши свойствами в `src/art/rig/wear.ts` (`TOPS`, `LEGS`, `FEET`, `HATS`) — она сама сядет на риг во всех
   позах; оружие нарисуй в `Weapon` (`src/art/rig/Rig.tsx`), наколку — в `TATTOO_ART` (`src/art/rig/tattoos.tsx`)
   с местом на теле, мебель — в `CellBackdrop` (`src/art/Scenes.tsx`) или `src/art/CellDecor.tsx`. Сцены — 360×280,
   пол на y≈236. Иконка вещи в магазине строится сама (`src/art/Icons.tsx`). Тест проверяет, что каждая вещь описана
   для рига.
3. Прогони `npm run sim`, если вещь заметно меняет силу или доход.
