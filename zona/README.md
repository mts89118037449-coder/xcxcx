# Зона — тюремная RPG для Telegram Mini App

Браузерка в жанре «тюремной» RPG из ВК, сделанная как Telegram Mini App. Весь игровой контент
(названия, баланс, тексты) свой, поэтому игра не завязана на чужой бренд.

**Что есть в игре**

- **Прогрессия:** уровни, опыт, три навыка (сила, ловкость, выносливость). Очки навыков за уровень и тренировки за деньги.
- **Работа:** 7 работ, тратят энергию. Энергия восстанавливается со временем.
- **Шмот:** 6 слотов, вещи за рубли и за золото, редкие трофеи с боссов.
- **Наколки:** постоянные бонусы, требуют уровень и авторитет.
- **Боссы:** 4 босса с откатом и шансом дропа.
- **Онлайн:**
  - общий босс «Бунт на централе»: его бьёт весь сервер, награда делится по урону;
  - PvP-наезды на живых игроков своего уровня (если подходящих нет, против бота);
  - рейтинг авторитета, счётчик онлайна.
- **Графика и анимации (полуреалистичная манера, всё нарисовано в SVG):**
  - персонаж собирается из слоёв: надетые шмотки, обувь, шапки, оружие и талисманы рисуются прямо на нём;
  - наколки появляются на коже (кнопка «Показать наколки» снимает верх);
  - руки растут вместе с силой, при низком здоровье появляются фингал и пластырь;
  - персонаж с нормальными пропорциями: объём градиентами, мышечный рельеф, щетина, складки одежды;
  - персонаж дышит и моргает;
  - фактура в сценах: грязные стены, сколы краски, свет из окна, зерно и виньетка;
  - вещи в магазине и инвентаре показаны картинками в той же манере, без эмодзи;
  - локации: Хата, Промзона, Двор. Меняется время суток в окне, мигает лампа, по конвейеру едут ящики,
    летят искры, ходит прожектор на вышке, клюёт ворона;
  - бои проигрываются удар за ударом: выпад, отдача, цифры урона, крит, нокаут;
  - боссы нарисованы тем же конструктором (вертухай, начкар, хозяин зоны).
- **Обустройство хаты:** 15 предметов мебели (матрас, одеяло, ковёр на стену, иконостас, тумбочка,
  стол с чифирбаком, радио, телевизор, аквариум, холодильник…). Всё купленное видно в сцене камеры и даёт бонусы.
- **Редактор персонажа:** лицо (32 варианта), телосложение, цвет кожи, имя (первая смена бесплатно).
- **Хата:** отделка стен и пола (9 вариантов, часть за золото) плюс 15 предметов мебели.
- **Дейлики:** 3 случайных задания на день, одинаковые весь день, сброс в полночь МСК, бонус за все три.
- **Поручения:** доска из 3 случайных заданий с таймером (5–60 мин), шансом провала, ускорением и сменой доски за золото.
- **Кланы:** создание (с 5 уровня), вступление, общак, прокачка до 10 уровня (+3% денег и +2 энергии за уровень всем),
  выгнать участника, передача главенства при уходе.
- **Соседи:** можно зайти в хату любого игрока из рейтинга или клана и «уважить» его (+1 авторитета, раз в день).
- **Энергия:** таймер до +1 и до полной, покупка +30 или полной за золото, чифир как запас, пак чифира за звёзды.
- **Ежедневный бонус** с серией и **реферальная система** (обоим игрокам по 50 золота).
- **Донат в Telegram Stars:**
  - пакеты золота;
  - VIP «Блатной статус» (x2 энергия, +20% денег, золото каждый день);
  - разовый стартовый набор.

## Как тебе платят

Цифровые товары в Telegram разрешено продавать только за **Telegram Stars** (валюта `XTR`), и игра
работает именно так. Платёжный провайдер не нужен.

1. Игрок жмёт покупку в «Ларьке». Сервер создаёт счёт (`createInvoiceLink`), Telegram показывает окно оплаты.
2. Telegram присылает `pre_checkout_query`. Сервер проверяет товар и цену.
3. Telegram присылает `successful_payment`, и сервер зачисляет покупку. Каждый платёж зачисляется ровно один
   раз: повторная доставка того же платежа ничего не начислит.
4. Звёзды копятся на балансе бота. Вывести их можно в TON через [Fragment](https://fragment.com):
   @BotFather → твой бот → *Payments / Stars balance*. Звёзды становятся доступны к выводу примерно
   через 21 день после покупки.

Команды `/paysupport` и `/terms` Telegram требует от ботов с платежами, они уже есть.
Команда `/stats` показывает админам число игроков, онлайн и выручку в звёздах.

Цены и содержимое пакетов меняются в `shared/content.ts` → `STAR_PACKS`.

## Запуск

Нужен Node.js **22.18+**: база — встроенный `node:sqlite`, TypeScript запускается без сборки.

```bash
cd zona
npm install
npm run build          # собрать фронтенд в dist/
cp .env.example .env   # заполнить BOT_TOKEN, PUBLIC_URL, ADMIN_IDS
npm start              # сервер: API + webhook + статика на PORT (8080)
```

**Настройка бота:**

1. Создай бота в [@BotFather](https://t.me/BotFather) и положи его токен в `BOT_TOKEN`.
2. Разверни сервер на HTTPS-домене (VPS + nginx/Caddy, Render, Railway и т.п.) и укажи его в `PUBLIC_URL`.
3. При старте сервер сам ставит webhook `PUBLIC_URL/tg/webhook` с секретом и кнопку меню «Играть».
4. По желанию: в BotFather → *Bot Settings → Configure Mini App* укажи тот же URL. Тогда игра открывается по
   ссылке `t.me/<бот>/app`.

База лежит в `data/zona.db` (или в `DB_PATH`). Её нужно бэкапить: там игроки и история платежей.

### Локальная разработка без Telegram

```bash
npm run dev:server   # сервер с DEV_AUTH=1 (вход без подписи Telegram)
npm run dev          # Vite на :5173 с прокси /api
# открыть http://localhost:5173/?dev=1   (?dev=2 — второй игрок и т.д.)
```

`DEV_AUTH=1` пропускает любого игрока без подписи Telegram, поэтому на проде его включать нельзя.

### Проверки

```bash
npm test       # логика игры + API: подпись initData, платежи, PvP, общий босс
npm run lint   # tsc --noEmit
```

## Устройство

```
shared/content.ts   весь контент и баланс: вещи, наколки, работы, боссы, донат-пакеты
shared/types.ts     типы ответа API
server/game.ts      игровая логика (чистые функции, покрыты тестами)
server/app.ts       HTTP API, webhook бота, приём платежей
server/db.ts        SQLite
server/auth.ts      проверка подписи Telegram initData
src/                клиент на React
src/art/            SVG-графика: персонаж (Character.tsx), локации (Scenes.tsx), арена боя
tests/              node:test
```

Сервер — единственный источник правды. Клиент только отправляет действия (`/api/action/<тип>`), а все
расчёты (бои, награды, энергия, покупки) делает сервер. Поэтому накрутить золото или ресурсы через клиент
нельзя.

### Рисованная графика

Герой, иконки вещей, наколок и лица боссов вырезаны из листа ассетов `docs/asset-sheet.jpg`
скриптом `python3 scripts/cut-sheet.py docs/asset-sheet.jpg` и лежат в `public/art/sheet` и `public/art/npc`.
Позы персонажа и 32 лица — из `docs/poses-sheet.jpg` и `docs/faces-sheet.jpg`
(`python3 scripts/cut-poses.py docs/poses-sheet.jpg docs/faces-sheet.jpg`). В хате персонаж сидит, во дворе
ходит, на промзоне толкает груз, в бою стоит в стойке и делает выпад. Лицо игрок выбирает сам:
первый раз бесплатно, смена за золото.
Боссы, зэки-соперники и сокамерники на фоне — из `docs/npc-sheet.jpg` (третий аргумент того же скрипта).
После поражения герой лежит, побитый — сидит в хате на полу.
Второй лист персонажей `docs/cast-sheet.jpg` (четвёртый аргумент): ещё 12 зэков-соперников, сокамерники на фоне и
хозяева экранов — Люба в ларьке, кольщик на наколках, смотрящий в рейтинге, начальник промзоны, командир ОМОНа
у бунта, лепила при ранении, адвокат с гревом.

Сейчас графика нарисована кодом (SVG) и служит временной. Игра умеет показывать иллюстрации от художника:
персонаж собирается из прозрачных слоёв, нарисованных в разных позах (сидит на шконке, стоит, в бою).
Полное ТЗ на графику, список всех файлов и промпты для нейросетей — в [`docs/ART_BRIEF.md`](docs/ART_BRIEF.md).
Картинки кладутся в `public/art/`, дальше нужно выполнить `npm run build`.

### Как добавить вещь или наколку с картинкой

1. Добавь запись в `shared/content.ts` (`ITEMS`, `TATTOOS` или `FURNITURE`).
2. Добавь её слои по списку из `docs/ART_BRIEF.md`; для временной графики нарисуй её в `src/art/Character.tsx` в словаре своего слота (`HEAD`, `BODY`, `LEGS`, `FEET`, `WEAPON`,
   `CHARM`, `TATTOO`) или в `CellBackdrop`/`CellLive` (`src/art/Scenes.tsx`) для мебели. Координаты персонажа —
   сетка 120×215, ступни на y≈208; сцены — 360×280, пол на y≈236. Иконка вещи в магазине строится сама
   (`src/art/Icons.tsx`), при необходимости поправь кадр в `cropFor`.

Если позже захочешь рисованную графику от художника, её можно подставить в эти же слоты картинками вместо SVG.
