# AGENTS.md — инструкции для Codex

## Язык и стиль
- Общайся с пользователем только на русском языке.
- Пиши кратко, по фактам, без вводных фраз и пустых обещаний.
- Сообщай только о реально выполненных действиях. Не утверждай, что APK собран, проверен или опубликован, если это не подтверждено артефактом/логом.
- При неполной информации явно указывай ограничения, не выдумывай результаты.

## Разработка
- Перед изменениями изучи структуру текущего репозитория и связанные инструкции.
- Сохраняй существующую функциональность. Исправления делай небольшими, проверяемыми шагами.
- Приоритеты для интерфейсов: понятная навигация, аккуратные отступы, адаптивность для телефона и телевизора, скорость и стабильность.
- По возможности выполняй доступные тесты и сборку; фиксируй их результаты и ошибки.
- Если требуется APK, сначала проверь, действительно ли проект является Android-проектом, и какие средства сборки доступны.

## Исторический контекст Claude
- Пользователь имеет экспорт Claude: 189 диалогов, файл памяти, проект и версии созданных артефактов. Экспорт не находится автоматически в этом репозитории.
- Не делай вид, что прочитал исходный архив, если он не прикреплён к текущему рабочему окружению.
- Если пользователь предоставил локальный пакет `claude_context_portable.zip`, используй индекс переписок и память только в отношении текущей задачи; при необходимости проверяй исходный диалог.
- Никогда не публикуй личные, юридические, финансовые сведения, токены, серверные адреса или исходные архивы Claude в репозитории без явной отдельной задачи и проверки содержимого.
